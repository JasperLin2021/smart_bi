# Schema Metadata Left Right Layout Design

**Goal**

将“表结构管理”弹窗从上下堆叠布局调整为左右布局，提升多表场景下的导航效率，并将右侧编辑区切换为页签式操作。

**Current State**

- 入口位于数据源设置页中的“表结构”按钮。
- 当前弹窗使用纵向结构：顶部工具栏，中部表折叠面板，底部关联关系表格。
- 多表切换依赖折叠面板，定位和编辑效率较低。

**Design**

- 保留现有弹窗、保存逻辑、自动检测逻辑和数据结构。
- 左侧新增表导航列表，展示表名、列数和当前选中态。
- 右侧改为单表编辑工作区。
- 右侧使用页签切换“字段管理”和“关联关系”。
- “添加关联”按钮移动到“关联关系”页签内部。
- 当没有选中表时显示空态；当没有任何表时显示整体空态。
- 弹窗宽度适当增加，保证左右布局在桌面端可用。

**Why This Approach**

- 改动集中在单个前端组件内，风险低。
- 不改变后端接口和保存 payload，兼容现有流程。
- 对已有用户心智改动小，只调整组织方式，不改核心操作。

**Validation**

- 能在左侧切换不同表并同步更新右侧内容。
- 能在字段页签新增、编辑、删除列。
- 能在关联关系页签新增、编辑、删除关系。
- 自动检测后左侧表列表与右侧选中项表现正常。
- 前端构建通过。
