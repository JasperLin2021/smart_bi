# Smart BI 企业级智能分析平台 PRD

## 1. 产品定位

Smart BI 面向企业内部经营分析、业务自助分析和 AI 问数场景。产品在现有 Vue 3 + FastAPI 系统基础上，从“智能问数工具”升级为“指标可信、资产可查、看板可用、权限可控”的企业级 BI 平台。

第一阶段不追求覆盖 FineBI 的全部能力，而是优先形成从数据接入、指标定义、问数分析、看板沉淀、告警订阅到权限审计的完整闭环。

## 2. 目标用户

- 管理层：查看经营看板、订阅报告、接收关键指标异常告警。
- 业务用户：自然语言问数、筛选维度、保存图表、查看已发布看板。
- 数据分析师：维护指标口径、发布数据资产、搭建业务看板。
- 平台管理员：管理组织、用户、权限、数据源、模型配置和系统运行状态。
- IT/数据工程：接入数据源、配置数据刷新、优化查询性能和安全策略。

## 3. 核心价值

- 统一指标口径：同一个经营指标在问数、看板、报告、告警中使用同一套定义。
- 降低分析门槛：业务用户可通过自然语言和可视化入口完成常见分析。
- 数据资产沉淀：把数据源、表、指标、看板统一纳入目录，支持搜索和复用。
- 企业级管控：组织、角色、菜单、操作和数据范围都可被审计和控制。

## 4. MVP 范围

### P0

- 数据源中心：数据库和 Excel 接入、连接测试、Schema 识别、字段说明、数据预览。
- 指标中心：指标定义、聚合方式、业务口径、负责人、单位、标签、状态。
- 智能问数：自然语言转 SQL、结果表格、推荐图表、SQL 透明展示、收藏图表、钻取。
- 看板中心：看板列表、创建、编辑基础信息、布局配置、从固定图表组装看板、发布。
- 数据目录：数据资产搜索、类型筛选、资产详情、组织和权限过滤。
- 告警与订阅：指标阈值告警、定时报表、邮件/企微/钉钉推送。
- 审计基础：查询历史、导出历史、权限变更、数据源变更和 LLM 调用记录。

### P1

- 自助数据集：字段选择、过滤、派生列、聚合、Join 建模、发布为主题数据集。
- 看板模板：经营、销售、采购、库存、财务、质量等常见模板。
- 协作：看板分享、公开链接、指定用户协作、版本管理。
- 运营后台：活跃用户、慢查询、热门指标、资产使用率。

### P2

- 多租户商业化：租户套餐、用量限制、品牌配置、白标。
- 大屏中心：集成 GoView 作为专业大屏设计和预览入口，由 Smart BI 控制登录态、角色权限和组织范围。
- 数据服务 API：指标 API、看板嵌入 SDK、Webhook。
- 智能分析增强：异常归因、自动洞察、图表自动推荐、指标解释 Agent。

## 5. 成功指标

- 问数成功率：P0 不低于 75%，P1 不低于 85%。
- 常用问题首屏响应：P0 不超过 5 秒，复杂查询不超过 30 秒。
- 看板搭建效率：业务用户 30 分钟内完成一个基础业务看板。
- 指标复用率：核心看板 80% 以上使用指标中心定义。
- 管理可控：所有数据源、看板、导出、查询都有审计记录。

## 6. 技术策略

- 后端继续使用 FastAPI、SQLAlchemy、Pydantic 和 PostgreSQL。
- Excel/文件分析继续使用 DuckDB。
- 第一阶段引入 Alembic 管理结构变更。
- 前端继续使用 Vue 3、TypeScript、Element Plus 和 ECharts。
- 暂不引入 Redis、Celery、ClickHouse、Doris 或 StarRocks，避免首期复杂度过高。
