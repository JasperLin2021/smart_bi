# Smart BI Phase 1 Roadmap

## 目标

Phase 1 将现有智能问数型 BI 产品化为可验收的企业级底座。交付重点是迁移可控、指标语义完整、数据资产可查、看板中心可用、权限边界清晰。

## 交付范围

- 产品文档：沉淀 PRD、阶段路线图、README 迁移说明。
- 迁移体系：引入 Alembic，后续新增表和字段均通过迁移管理。
- 指标语义：补充指标负责人、单位、聚合方式、标签、状态、业务口径。
- 数据目录：支持表、指标、看板三类资产的发布、查询、详情和权限过滤。
- 看板中心：支持看板 CRUD、发布、组织隔离和基础页面。
- 自助数据集：支持字段、过滤、派生列、Join、聚合配置，并可发布进入数据目录。
- GoView 大屏：以受控入口集成 GoView，支持设计/查看模式、组织上下文和审计记录。
- 运营后台：提供用户、问数、资产、看板、数据集、大屏和错误审计概览。
- 前端入口：新增数据目录和看板中心菜单、路由和页面。

## 非目标

- 不重写后端语言。
- 不在 Smart BI 内自研完整拖拽式复杂大屏设计器，专业设计能力交给 GoView。
- 不引入新的 OLAP 引擎或任务队列。
- 不实现公开链接、多人协作、版本管理和权限申请流程。

## 验收标准

- 后端全量测试通过。
- 前端生产构建通过。
- SQLite 和 PostgreSQL 均可执行 Alembic upgrade。
- 普通用户无法访问其他组织私有资产或草稿看板。
- 企业管理员可管理本组织资产，超级管理员可跨组织管理。
